A proposed visual refresh for **fornbeaino**, bringing a more cohesive and character-driven direction to the bakery's social media 

The project explores how typography, graphic elements, and food photography can work together to better reflect the brand's craftsmanship, quality, and humble roots

![FB1](https://res.cloudinary.com/iquk7s3z/image/upload/v1792966503/FB-01.webp)

fornbeaino already has a well-established visual identity, one that reflects the simplicity and pride behind the bakery

That made this project less about fixing what was broken and more about exploring what else the brand could be

How could its existing character be expressed through a different visual language?

Could typography, graphic elements, and food photography bring a new layer of personality to its social media while staying true to what makes fornbeaino, fornbeaino?


---


Currently, the brand only has one design element: 

**The lines** (present in the logo)

These lines are used in the wrapping paper as a pattern

Because these lines are very simple, it creates a  very typical and predictable pattern

We need a complimentary, more unique pattern/design element  to further differentiate the brand from it’s competitors

![FB2](https://res.cloudinary.com/iquk7s3z/image/upload/v1792966634/FB-02.webp)

Using the letter “i” from the logo we can reflect, repeat then elongate it to create a distinctive pattern

This can be used as both a pattern or a design element

Below, we can see different examples on how we can use the design elements to enhance the brand visuals

![FB3](https://res.cloudinary.com/iquk7s3z/image/upload/v1792966532/FB-03.webp)

The typeface used for the furnbeaino logo **(Museo)** fits the brand perfectly

For the New Proposed Typography, we want to honor the logo by using the same typeface superfamily

We’ll leave the main Museo font for the logo and use **Museo Rounded Slab** as the main brand typeface

And to further make the messages more inviting, they should always be written in all lowercase form

The complimentary font **Maytra** makes it seem as if it’s a signature from Toni Beaino himself after the main message!

![FB4](https://res.cloudinary.com/iquk7s3z/image/upload/v1792966501/FB-04.webp)

After creating a New Visual Direction, we have to create some social media posts to see it in action!

Every detail carries intention:

Lowercase expressions that reflect the humble valuesHandwritten font perfectly complimenting the main message

Dashed lines being used to their full potential, giving more meaning to the brand and it’s logo

New design element serving as guides for text expressions and framing the human subjects

All these different aspects combine to create a cohesive visual brand identity that serves furnbeaino and it’s core values
